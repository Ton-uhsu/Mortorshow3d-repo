# Mortorshow3d

เว็บไซต์ Proof of Concept (POC) สำหรับแผนที่ 3D งาน Motor Show
ที่ออกแบบมาเพื่อช่วยให้ผู้ใช้งานค้นหาบูท มองเห็นภาพรวมของพื้นที่
และเข้าใจเส้นทางเดินไปยังจุดหมายได้ง่ายกว่าแผนที่งานแบบทั่วไป
พร้อมรองรับประสบการณ์ใช้งานที่ง่ายและสะดวกบนโทรศัพท์มือถือ

## Project Concept

แนวคิดของโปรเจกต์นี้คือการนำแผนที่ 3D มาใช้เป็นเครื่องมือช่วยนำทางภายในงานแสดงสินค้า
โดยเฉพาะงาน Motor Show ที่มีพื้นที่ขนาดใหญ่ บูทจำนวนมาก
และมีความซับซ้อนในการหาตำแหน่งจริงเมื่ออยู่ภายในฮอลล์

POC นี้มุ่งพิสูจน์ว่า web-based 3D map สามารถช่วยให้ผู้ใช้:

- มองหาบูทที่ต้องการได้เร็วขึ้น
- เข้าใจตำแหน่งของตัวเองเทียบกับพื้นที่รอบข้างได้ง่ายขึ้น
- วางแผนเส้นทางเดินภายในงานได้สะดวกขึ้น
- ได้ประสบการณ์การใช้งานที่ทันสมัยและน่าสนใจกว่าแผนที่ 2D แบบเดิม
- ใช้งานได้สะดวกบนมือถือซึ่งเป็นอุปกรณ์หลักของผู้เข้าชมภายในงาน

## Value ที่โปรเจกต์ต้องการส่งมอบ

### สำหรับผู้เข้าชมงาน

- ลดความสับสนในการหาบูทหรือจุดหมายภายในงาน
- มองเห็นภาพรวมของพื้นที่จัดงานได้ชัดเจน
- ช่วยตัดสินใจเลือกเส้นทางเดินที่เหมาะสม
- เพิ่มความสะดวกและประสบการณ์ที่ดีในการเดินชมงาน
- ใช้งานได้ง่ายแม้เปิดผ่านหน้าจอมือถือระหว่างเดินอยู่ภายในงาน

### สำหรับผู้จัดงานหรือเจ้าของโปรเจกต์

- ใช้เป็นต้นแบบเพื่อทดสอบความเป็นไปได้ของ 3D navigation experience
- ใช้สื่อสาร vision ของผลิตภัณฑ์กับผู้มีส่วนเกี่ยวข้องได้ชัดเจน
- ใช้ต่อยอดเป็นระบบจริงในอนาคตได้ ทั้งฝั่ง visitor experience และ exhibitor service

## Main Goal

สร้างเว็บไซต์สำหรับใช้เป็น POC ของแผนที่ 3D งาน Motor Show
เพื่อช่วยให้ผู้ใช้งานสามารถมองหาตำแหน่งของตัวเอง วางแผนเส้นทางเดิน
และไปยังบูทที่ต้องการได้ง่ายขึ้น เร็วขึ้น และเข้าใจภาพรวมของพื้นที่จัดงานได้ชัดเจนกว่าเดิม
โดยต้องคำนึงถึงการใช้งานบนโทรศัพท์มือถือเป็นสำคัญ

## เป้าหมายของ POC

- สร้างประสบการณ์แผนที่ 3D ที่ดูเข้าใจง่ายและใช้งานได้จริงบนเว็บ
- แสดงตำแหน่งบูทหรือจุดสนใจสำคัญภายในงานในรูปแบบที่ชัดเจน
- รองรับแนวคิดการค้นหาบูทและโฟกัสจุดหมายปลายทาง
- วางรากฐานสำหรับระบบนำทางหรือ route guidance ในอนาคต
- รองรับ mobile-friendly experience ที่ใช้งานง่ายจริงในสถานการณ์เดินงาน
- ใช้เป็นต้นแบบสำหรับการคุยงาน ออกแบบฟีเจอร์ และทดสอบความเหมาะสมเชิงผลิตภัณฑ์

## Proposed Features

ฟีเจอร์หลักที่เหมาะกับ POC ระยะแรก:

- แสดงแผนที่ 3D ของพื้นที่จัดงาน
- แสดงบูทพร้อมชื่อแบรนด์หรือรหัสบูท
- ค้นหาบูทตามชื่อแบรนด์หรือรหัสบูท
- เลือกบูทแล้วโฟกัสกล้องไปยังตำแหน่งเป้าหมาย
- แสดงตำแหน่งปัจจุบันของผู้ใช้ในบริบทของแผนที่
- แสดงเส้นทางเดินแบบเข้าใจง่ายจากจุดเริ่มต้นไปยังบูทเป้าหมาย
- แสดงข้อมูลบูทเพิ่มเติมเมื่อคลิกหรือเลือกจุดสนใจ
- ออกแบบ UI ให้เหมาะกับมือถือ เช่น ปุ่มกดง่าย ข้อความอ่านง่าย และ flow ไม่ซับซ้อน

## ขอบเขตของเวอร์ชัน POC

เวอร์ชันนี้ควรเน้นการพิสูจน์ concept ก่อนระบบ production จริง
ดังนั้นเป้าหมายสำคัญคือให้ผู้เกี่ยวข้องเห็นภาพว่า:

- 3D map บนเว็บใช้งานได้จริง
- ผู้ใช้สามารถเข้าใจพื้นที่ได้เร็วกว่าเดิม
- การค้นหาและการมองหาเส้นทางมีศักยภาพในการช่วยการเดินงานจริง

สิ่งที่ยังไม่จำเป็นต้องสมบูรณ์ในระยะแรก:

- ระบบระบุตำแหน่ง indoor ที่แม่นยำระดับ production
- navigation engine ที่สมบูรณ์ทุกกรณี
- backend ที่ซับซ้อน
- dashboard หรือระบบจัดการหลังบ้านเต็มรูปแบบ

## Mobile Experience Direction

เนื่องจากการใช้งานจริงส่วนใหญ่มีแนวโน้มเกิดขึ้นบนโทรศัพท์มือถือ
POC นี้จึงควรให้ความสำคัญกับ mobile experience ตั้งแต่ต้น เช่น:

- เปิดใช้งานได้ง่ายบนหน้าจอมือถือ
- ปุ่มและ control ต้องกดง่ายระหว่างเดิน
- ข้อความสำคัญต้องอ่านได้ชัดโดยไม่ต้องซูม
- การค้นหาบูทและการดูเส้นทางต้องทำได้ในไม่กี่ step
- 3D view ต้องไม่ซับซ้อนเกินไปสำหรับผู้ใช้ทั่วไป

## Tech Stack

stack ที่เลือกใช้สำหรับ POC นี้:

- React
- Vite
- Three.js
- @react-three/fiber
- @react-three/drei
- Tailwind CSS

เหตุผลที่เลือกชุดนี้:

- พัฒนาเว็บ POC ได้เร็ว
- เหมาะกับงาน 3D บน browser
- จัดการ interactive scene ได้ยืดหยุ่น
- ทำ UI ที่ mobile-friendly ได้ง่าย
- ต่อไปสู่ฟีเจอร์ search, booth focus, และ route guidance ได้ดี

## Technical Direction

แนวทางการใช้งาน stack นี้ในโปรเจกต์:

- React + Vite ใช้เป็นฐานของ frontend web app
- Three.js และ React Three Fiber ใช้สำหรับแผนที่ 3D และ interaction ใน scene
- Drei ใช้ลดงาน boilerplate ของกล้อง control, helper, และ 3D utility ต่าง ๆ
- Tailwind CSS ใช้สำหรับสร้าง UI ที่ responsive และเหมาะกับการใช้งานบนมือถือ
- โครงสร้างข้อมูลควรรองรับ booth data, point of interest, และ navigation state สำหรับการต่อยอดในอนาคต

## Future Plan

แนวทางต่อยอดหลังจาก POC แรก:

- เพิ่มระบบค้นหาและ filter ที่ดีขึ้น
- เพิ่ม route guidance ที่ชัดเจนขึ้น
- รองรับการเลือกจุดเริ่มต้นหลายแบบ
- เพิ่มรายละเอียดบูท เช่น โปรโมชัน แบรนด์ หรือกิจกรรม
- รองรับ mobile-first experience สำหรับการใช้งานภายในงานจริง
- เชื่อมต่อข้อมูลจริงของงานเพื่ออัปเดต layout หรือข้อมูลบูทได้ง่าย
- พัฒนาไปสู่ระบบแผนที่ interactive สำหรับ event ขนาดใหญ่อื่น ๆ
